1. PROJECT WORKING

The project implements a SimpleLoader for loading and executing a
32-bit statically linked ELF executable.

The main files are:

loader.c: Implements the main loading functionality. It opens the
  ELF file, reads it into memory, finds the program headers, identifies
  the PT_LOAD segment containing the entry point, maps the required
  memory using mmap(), copies the segment contents and executes the
  _start() function.

launch.c: Acts as the launcher. It takes the ELF executable as a
  command-line argument and performs basic ELF validation before calling
  load_and_run_elf().

loader.h: Contains the required declarations and header files.

fib.c: Test executable used with the SimpleLoader.

Makefiles: Compile the loader, launcher and test case and create the
  shared library lib_simpleloader.so.


2. ERROR HANDLING

Important errors are checked throughout the program.

launch.c checks:
- Invalid number of command-line arguments.
- Failure to open the file.
- Failure to read the ELF header.
- Invalid ELF magic number.
- Non-32-bit ELF files.

loader.c checks:
- Failure to open the executable.
- lseek() failures.
- malloc() failure.
- read() failure or incomplete read.
- mmap() failure.

loader_cleanup() releases the allocated memory, mapped segment and
open file descriptor after execution.
